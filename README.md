# Home Monitor
esp32 and RaspPI code code for home monitor setup.

Monitor using esp32 c3 mini combined with multiple of the Dallas 1-wire temperature sensors. Monitor boiler flow and return, and hot water tank, and ambient.

System Overview:
* S-PLAN.
* HW zone valve. 2000L HW tank.
* CH zone valve.
* TADO X smart thermostat and receiver.
* Greenflame Bioflame 28 kW biomass boiler.

Hardware:
* ESP32-C3 Super Mini Development Board.
* Raspberry PI 5.
* DS18B20 Sensor Probes.

Software:
* ESP32: Arduino Sketch project
* Rasp PI: Home Assistant
